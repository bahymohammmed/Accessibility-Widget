# Accessible Visitor Toolkit

Free bilingual Arabic/English website accessibility widget and demonstration website. Includes visual controls, text-to-speech, caption preferences, and fixed sidebar mode.

This is not a WCAG 2.2 AA certification.

## Installation

```html
<script src="/accessibility-widget.js" defer></script>
```

## Fixed sidebar

```html
<script src="/accessibility-widget.js" data-avt-mode="sidebar" data-avt-side="right" defer></script>
```

THE TOOLKIT

Thoughtful accessibility tools.

Practical visitor preferences, organized to be discoverable and easy to operate.

Visual preferences

Text size, high contrast, grayscale, link emphasis, text spacing and a reading guide.

Read aloud

Listen to page content or selected text with supported browser speech voices.

Hearing support

Caption preferences, supplied transcripts, visual alerts and live-caption integration hooks.

Flexible placement

Floating launcher or a fixed sidebar on either side, with mobile-friendly behavior.

Bilingual by design

Arabic/English control labels and right-to-left interface support, with mixed-language media options.

Privacy-first

No tracking by default. Optional aggregate adoption metrics can be deployed separately.

GET STARTED

Install in minutes.

A simple script tag brings the widget to your website. No framework or build system required.

1
Download the script

Use the repository's accessibility-widget.js file.

2
Host it with your website

Place the file at the path used below.

3
Add the script tag

Reload your page and check the floating launcher.

HTML · Floating mode
<script src="/accessibility-widget.js" defer></script>
For a permanent right sidebar, add data-avt-mode="sidebar" data-avt-side="right" to the script element. Change right to left if preferred.
